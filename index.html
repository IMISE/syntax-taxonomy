The SynTax Taxonomy: Use Cases for Synthetic Data Generation based on Data Requirements

Abstract

Access to real-world clinical data is usually restricted due to privacy regulations, ethical considerations, and legal constraints. Synthetic data has emerged as a promising approach to address this challenge. However, existing comparisons of synthetic data generation methods often focus on methodological aspects or utility metrics without explicitly considering the intended application context. This work introduces a use-case-oriented taxonomy ‘SynTax’ to structure synthetic data generation scenarios based on their primary objectives and corresponding data requirements. The taxonomy was developed using an expert-based approach informed by existing literature and organizes use cases hierarchically, reflecting increasing requirements. Identified use cases include conformance validation, performance evaluation, system validation, data demonstration, education, data enrichment, and analysis. The proposed taxonomy provides a structured framework for comparing synthetic data generation tools based on their intended use case and associated data requirements. It supports users in selecting appropriate tools for specific application scenarios and offers guidance for developers to identify gaps in current tool capabilities. Future work should extend this approach through systematic benchmarking and evaluation of how well tools meet the requirements of different use cases.

Methodology

A wide range of synthetic data generation tools has been developed in recent years, each targeting different application scenarios. To address a comparison of tools across use cases, an exemplary set of synthetic data generation tools was selected. The selection was based on an expert-driven process combined with a targeted search in the literature and software repositories (e.g., nfdi.software and ToolPool Gesundheitsforschung). The inclusion criterion was open-source availability. Based on this criterion, eleven tools were selected. These software repositories focus on software utilized in the context of medical research, which was the primary field of expertise of the experts consulted. The selected synthetic data generation tools were mapped to the SynTax use cases through a review of their primary literature. A tool was assigned to a use case if the corresponding application scenario was explicitly described in the respective primary literature as an intended use, development objective, or evaluation context.

Tools Comparison

The reviewed tools included MDClone, medGAN, MultiNODEs, PerfGen, Synthetic Data Vault (SDV), SemSynth, Synthea, SynthCity, SynthMD, SYNDERAI, and Variational Autoencoder Modular Bayesian Networks (VAMBN). MDClone was used as a proprietary comparator because it is frequently referenced in the literature on synthetic health data.

The table maps the selected tools to the identified use cases based on explicit statements in the primary literature. The mapping shows that the reviewed tools predominantly target one or two use cases rather than maximizing use case coverage. It should be noted that the mapping reflects the selected subset of tools and their positioning in the literature. In particular, the focus is on tools in the medical research domain.

The most frequently represented category is 7. Analysis with six tools positioned for this purpose. This can be attributed to the predominant role of synthetic data in healthcare for analytical applications. Overall, the mapping indicates that tool suitability is highly use-case-dependent and that no single tool explicitly covers all identified application scenarios.
