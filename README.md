# The SynTax Taxonomy — GitHub Pages site

This folder contains a small, static, single-page website for **The SynTax Taxonomy**.

## Local preview

Open `index.html` directly in a browser or serve this folder with any local static web server.

## Later publication with GitHub Pages

After this folder has been pushed to its GitHub repository, enable GitHub Pages in the repository settings and select the repository root on the `main` branch as the source. No build step is required.

The site has deliberately not been deployed or connected to a remote repository yet.
